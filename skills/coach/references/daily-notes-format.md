# Daily Notes Format

Daily notes are located in `{vault}/Daily Notes/YYYY-MM-DD.md`

## Standup Entry Format

Append standup summaries under a `## Coach` section:

```markdown
## Coach - 2026-01-11 09:30 #standup

**Goals reviewed:** #goal/learn-rust #goal/api-refactor

- Learn Rust: 35% → 40%, resolved lifetime confusion ✅
- API Refactor: Started planning, next: schema design

**Blockers:** None
**Energy:** 7/10
```

## Tags

- Use `#standup` for standup entries
- Reference goals with `#goal/goal-name`
- Reference projects with `#project/project-name`
- Use topic tags like `#topic/distributed-systems`
