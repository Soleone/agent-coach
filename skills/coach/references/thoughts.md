# Thoughts Format

Thoughts are anything on mind: world events, life things, passing observations.

Found in journal entries as `#thought:` tag.

## Format

```markdown
#thought: Saw interesting article about Rust async runtime comparisons
#thought: Feeling tired today, maybe take it easy on complex tasks
#thought: Remember to call Mom this weekend
```

## Detection

Grep for `#thought:` in `{vault}/{journals}/`.
